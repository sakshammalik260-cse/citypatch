# CITYPATCH Data Notes

## Civic Patch Library v1

CITYPATCH currently uses a prototype Civic Patch Library containing 12 modular civic infrastructure components across four categories:

- Pedestrian Safety
- Accessibility
- Heat & Public Space
- Water & Drainage

## Current Data Status

The current cost ranges and installation-time estimates are indicative prototype values created for MVP development.

They must NOT be presented as:

- verified municipal quotations
- contractor quotations
- official government rates
- construction-ready estimates
- engineering specifications

## Before Final Demonstration

The following data should be researched and strengthened:

- Indian supplier pricing
- relevant government or municipal references where available
- accessibility standards
- pedestrian infrastructure guidance
- drainage and stormwater guidance
- installation assumptions
- material assumptions

Sources should be documented with:

- source name
- source URL
- date accessed
- relevant module
- value or requirement supported by the source

## Safety Principle

CITYPATCH generates preliminary civic intervention proposals.

AI-generated recommendations and visualizations are not construction approval.

Final dimensions, structural requirements, accessibility compliance, drainage design, traffic safety, utility conflicts, and other site-specific engineering requirements must be verified by qualified professionals before physical implementation.

## Core Principle

AI understands the problem.

CITYPATCH constrains the solution.

Humans approve physical deployment.
